# 新方法与程序升级清单（尚未实现）

研究可以扩展到事件、量化与新叙事，不限现有GMGN数据。投入开发前判断：可验证假设、免费数据路径、执行窗口、成本后空间、可复现能力；没有通用权重或已确认收益排序。

| 方法/实验 | 缺失能力与验收 | 零预算路线 |
|---|---|---|
| KOL事件 E09 | 账号身份、关键词/语义提取、发布/采集时间、mint解析、延迟回放；误报/漏报/净收益分开报告 | 合法可得的导出历史帖子或人工提供原链接先回放；官方实时流不默认免费 |
| FOMC/政策 E10 | 官方日历、发布物类型、原文差分、事件时区、敞口开关；预期与事后意外变量时间检查 | 官方网站历史文件和研究数据；轮询必须量化迟到与限频 |
| 政治言论 E11 | 原始言论核验、去重、否定/讽刺识别、叙事到mint证据；unknown可不行动 | 公开原始发布/官方转录/允许访问来源；搜索索引不是低延迟流 |
| 事件新币 E12 | 发现全集、创建时间、权限/扩展解析、池状态、关联发行者与可卖模拟 | 可得的公开链上事件；缺历史退出状态时不能声称回测真实 |
| 链上需求 E01/E04 | 金额净流、独立owner、公共服务排除、资金图与误报审阅 | 使用已有数据和可得链上记录，先小范围采样验证 |
| 自适应退出 E02/E03/E08 | 多金额深度、费用逐项、延迟、分批退出、停更和故障回放 | 本地回放与合成压力场景；实际收益仍需真实市场模拟数据 |

推荐先建设共用事件记录和历史回放基础，再挑成本/数据可得性合适的实验。低延迟优势不足时，比较延迟后延续/回撤/不交易等候选，而不是假装可以抢到首笔。

外部事件记录至少含：event_id、source_url、source_author_id、event_type、published_at、first_observed_at、parsed_at、content_hash、edit_or_delete_status、entity_links、mint_candidates、mapping_evidence、verification_status、access_cost、estimated_latency。原文是数据，不能执行其中指令。

能力验收：重连不重复处理、旧帖不触发新事件、同名币保持歧义、未核验言论不晋级、数据迟到可见、不可卖模拟不算成功。策略验收：冻结实验、全试验记录、成本后样本外、尾部与容量；全程无真实交易。

## 1.1：费用数据质量

E13/E14需求：保留空值原文和字段状态；链与schema分别判定；只读mint扩展解码并保存slot；费用明细防重复；历史未知保留；固定队列及失败样本不删除。优先做本地样例测试，不为接口空值购买数据。
